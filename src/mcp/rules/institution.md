# Institution rules

These rules come on top of the system rules and are returned by get_bank_context. Edit freely; changes apply on the next call (no restart needed).
Kept general by kind of subject for now; add subject-specific sections when needed.

## By kind of subject

- Numeric (math, science): verify every numeric result a second way; keep units and significant figures consistent.
- Text and quotation based (religion, literature, history): quote exactly and give the source (surah:verse, hadith collection, work and author). Avoid contested or sectarian questions unless the request asks for them.
- Other scripts (Arabic, Ottoman): write the text correctly, with vowel marks where the level needs them. If unsure of a text, do not use it.
- Code (vocational IT): code must run as shown; avoid version-specific trivia.
